# Java-Script

A collection of JavaScript practice exercises covering fundamental concepts, array methods, and exam-style problems.

## Repository Structure

| Directory | Description |
| --- | --- |
| `Array-Methods/` | Examples of JavaScript array methods |
| `Exam-1/` | Practice questions and solutions for Exam 1 |
| `Exam-2/` | Practice questions and solutions for Exam 2 |
| `String-Methods/` | String method examples |

## Requirements

- [Node.js](https://nodejs.org/) 18 or later

## Running the Examples

Run an exercise directly with Node.js:

```bash
node Exam-1/Q1.js
node Exam-2/Q01.js
node Array-Methods/at.js
```

Open an HTML example in a browser:

```text
Exam-1/Q27.html
```

## Topics

- Variables and operators
- Functions and arrow functions
- Conditional statements and loops
- Arrays and array methods
- String methods
- Objects and basic problem-solving
